
It is a Neovim plugin that provides integration with Zotero. It is forked but has significanly diverged from zotcite - It uses FzfLua as picker and different actions I needed for my workflow with zotero, latex / markdown writing (I mostly search for a reference with it and open in sioyek, search through annotations stored in zotero database).

Do refer original zotcite plugin for details on functionality.

# Installation

It is not recommended to use this, some of paths are hardcoded for personal use.
